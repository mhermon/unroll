Read agent traces and chat logs in VS Code.

Unroll shows a JSONL conversation file as a chat you can scroll, search and filter. Use it on runs you record yourself, like Claude Code or Codex sessions, or on datasets you download from Hugging Face or a repo, to see what the conversations actually look like.

The same file, easier to read.

DatasetsC ⇧J⇧K

Browse a file of many traces

When each row holds a whole conversation, as in agent-trajectory datasets from Hugging Face, Unroll lists the rows with their size and outcome. Filter the list by id, field or message text, and read each row’s other fields, like model, reward or patch, above its conversation.

Supported formats

Open .jsonl, .ndjson or .json files directly. Unroll recognizes these message formats.

Claude Code, Anthropic
Message envelopes, text, thinking, tool use and results
Codex, OpenAI Responses
Response items, messages, function calls and outputs
OpenAI Chat Completions
Role and content messages with tool calls
Gemini
Parts, function calls and function responses
Vercel AI SDK
Text, reasoning and tool parts
OpenTelemetry GenAI
Input and output message attributes on spans
LangChain, LangGraph
Human, AI and tool messages, including state dumps
Chat and trace datasets
One conversation per row: ShareGPT, SWE-agent, OpenHands, τ-bench and similar

Exports differ between tools and versions, so some files may only partly match. Records that aren’t recognized are still shown as raw events. Parquet isn’t supported. Format details

Install

Unroll is a free preview release for desktop VS Code 1.96 or newer. It’s distributed as a VSIX file on GitHub.

Download the VSIX Example file

  1. Install the VSIX

    In the Extensions view, open the … menu and choose Install from VSIX…

  2. Open a file

    Any .jsonl, .ndjson or .json file, or the example session.

  3. Open it in Unroll

    Right-click the file and choose Unroll: Open as Agent Trace. The normal text editor stays the default.

code --install-extension unroll-<version>.vsix

Privacy

The extension only reads and displays the file you open. Privacy details

  • No telemetry, account or API key
  • Doesn’t run recorded tool calls
  • Doesn’t change your files
  • Doesn’t load remote images from file content
  • Doesn’t upload anything

Try a chat log or an agent trace.

Start with the same synthetic files shown above, or open a conversation file you already have. If it doesn’t display correctly, share a small sanitized sample in an issue.
