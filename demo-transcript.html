Walkthrough transcript

A text version of the 48-second walkthrough on the home page. It was recorded from the extension’s viewer running inside a drawn, VS Code-style window, using two synthetic example files. The window frame, context menu and conversation dropdown are drawn for the recording; everything inside the preview is the extension’s own output.

What happens

TimeOn screen
0:00A Claude Code session is open as raw JSONL. Every line starts with the same envelope fields, so the conversation isn’t readable. The file is opened with Unroll: Open as Agent Trace and appears as a conversation.
0:07A Bash tool call shows its formatted arguments. Clicking result at step 4 shows the call and its result together.
0:12The result switches to its original JSON record, with every field from the log.
0:16The record’s line opens in the source file beside the preview, on line 4.
0:22Searching for tool_calls finds an assistant message and a Grep call whose arguments contain the text.
0:29With Follow latest on, two new records are added to the file. The tool result and the final answer, with a table, appear at the bottom.
0:36A chat dataset with two conversations opens in another tab. The conversation picker switches to the second one.

The tool calls shown are recorded data. Unroll doesn’t run them.
