Using Unroll

How to open a conversation file, move around it, and check the original records. To follow along, download the example file.

Open a file

Open any .jsonl, .ndjson or .json file, then choose Unroll: Open as Agent Trace. It’s in the file’s right-click menu, the editor’s preview icon and the Command Palette. You can also use Reopen Editor With… → Agent Trace (Unroll).

The normal text editor stays the default for these file types.

Search and filter

Press CtrlF (CmdF on macOS) or / to search. Search covers message text, tool names, arguments and results.

The role tabs (All, User, Assistant, Tool, System) filter the selected conversation. Files with more than one conversation get a picker next to the search box. Step numbers always match the original file, including when you filter.

Tool calls

Expand a call to see its arguments. Below it, result at step N isolates the call and its result together; clear the filter to go back. Results stay in chronological order in the main list.

Pairing uses the call IDs in the trace. Gemini records without IDs can pair by tool name. When a match is ambiguous, Unroll leaves it unpaired rather than guessing.

Original records and source

Hover a step to show three actions:

  • Record shows the original JSON for that step.
  • Copy copies the step’s content.
  • Ln opens the source file beside the preview at that line.

For a single JSON array, the source link opens the start of the document. Record previews are capped at 2,097,152 characters.

Files that are still being written

The preview updates as the source changes, including unsaved edits. Turn on Follow latest (F) to keep the newest matching steps in view while new lines are added to the file. Scrolling up or changing a filter pauses following.

A half-written final JSONL line doesn’t hide the valid records before it.

Keyboard

Press ? in the preview for the full reference.

KeysAction

[]Previous / next page (60 steps per page)
ROOriginal record / open source line
FFollow latest
TTrajectory map

?Shortcut reference

Shortcuts apply to the focused preview. Single-letter keys are ignored while you type in an input. Rebind any command in VS Code’s Keyboard Shortcuts editor.

Command and setting IDs keep the chatview.* prefix for compatibility with earlier builds.

The trajectory map covers every filtered step, colored by role. Click a tick to jump there; the page changes with it.

Formats

Files can be JSONL, NDJSON or a single JSON array. These record shapes are recognized:

SourceRecognized content
Claude Code, AnthropicMessage envelopes, text, thinking, tool use and tool results
Codex, OpenAI Responsesresponse_item and event_msg records, messages, function calls, custom tools and outputs
OpenAI Chat Completionsrole / content messages and tool_calls
GeminiModel messages, parts, function calls and responses
Vercel AI SDKText, reasoning and tool parts
OpenTelemetry GenAIgen_ai.input.messages and gen_ai.output.messages span attributes
LangChain, LangGraphHuman, AI and tool messages, including nested state dumps
ShareGPT, datasetsConversation and message envelopes

Records that don’t match any shape remain available as events. Provider names describe compatible formats, not affiliation.

Content counts

Click the document total in the header to cycle between estimated tokens, words and Unicode characters. Counts include recognized text, reasoning, tool names, arguments and results, and leave out envelopes and non-text payloads.

The total describes recorded text across the whole file. It isn’t the context size of any single request, and it isn’t billed usage.

Limits

  • Preview release for desktop VS Code 1.96 or newer. It needs a Node extension host, so it doesn’t run in standalone vscode.dev.
  • The default maximum file size is 100 MB. Change it with Unroll: Max File Size MB (chatview.maxFileSizeMB).
  • Parsing is synchronous and in memory, not streamed. Very large single records and broad searches can be slow.
  • Parquet files and editing belong to the separate browser/Python app, not this extension.

Troubleshooting

If a file shows no recognized messages, turn on metadata events in View and look at the source. Invalid JSONL lines are listed in an expandable notice at the top of the preview. If the preview fails to load, reopen it and check the Unroll output channel.

Report a problem with your extension version, VS Code version, OS and a small sanitized example. Never attach credentials or private conversations.

No telemetry, account, provider calls or remote trace images. Processing happens in the extension host and webview, which can be your remote development environment. Privacy details
