Using RunTranscript

Open a JSONL, NDJSON or JSON trace in VS Code, then choose RunTranscript: Open as Agent Trace from the Command Palette or the file’s context menu. Try the synthetic checkout example.

Search and navigate

Press Ctrl/Cmd+F or / to search message text, tool names, arguments and results. Role tabs filter the selected conversation. The conversation picker appears for multi-conversation datasets. Step numbers remain tied to the original trajectory across filters.

The trajectory map covers all filtered steps. Click a tick to jump; paging follows automatically. The viewer renders 60 steps per page.

Inspect a tool call

Expand its arguments, then follow “result at step…” to isolate the call and its result. Clear the filter to return. Results remain in chronological order. Pairing uses explicit IDs; Gemini records without IDs can pair by tool name. Ambiguous matches are not guessed.

Original records and source

Hover a message to reveal Record, Copy and its L… source-line button. Record shows the original JSON. The line button opens the source beside the preview. JSON arrays link to the beginning of the document. Record previews are limited to 2,097,152 characters.

Follow updates

Source edits, including unsaved changes, update the preview. Follow latest keeps the newest matching steps in view as records are appended. Scrolling up or changing filters pauses following. A half-written final JSONL line does not hide earlier valid records.

Formats

Recognized shapes include OpenAI role/content/tool_calls messages; Codex response_item and event_msg records; Anthropic content blocks and Claude Code message envelopes; Gemini parts; Vercel AI SDK parts; OpenTelemetry gen_ai.input.messages and gen_ai.output.messages span attributes; LangChain human/ai/tool messages; and ShareGPT conversations or messages envelopes. Unknown records remain available as events. Provider names describe compatibility, not affiliation.

Limits and troubleshooting

This is a preview release for VS Code 1.96+. It needs a desktop Node extension host and does not run in standalone vscode.dev. The default maximum file size is 100 MB; change RunTranscript: Max File Size MB in Settings (identifier chatview.maxFileSizeMB). Parsing is synchronous and in memory. Very large individual records and searches can be expensive. Parquet and editing belong to the separate browser/Python application and are not extension features.

If a file shows no recognized messages, enable metadata events in View and inspect the source. Invalid JSONL lines appear in an expandable notice. If the preview fails, try reopening it and inspect the RunTranscript output channel. Report a reproducible problem with versions, OS and a sanitized example.

Content counts

Click the document total to cycle through estimated tokens, words and Unicode characters. Counts include recognized text, reasoning, tool names, arguments and results. They exclude envelopes and non-text payloads. The total is recorded text across the document, not a request’s context size or billed model usage.

Privacy

No extension telemetry, account, provider calls or remote trace images. Processing happens in the extension host and webview, which can include your remote development environment. Read the privacy details.
