Privacy

The RunTranscript extension has no telemetry, analytics, model-provider connection or account system. It reads the document you open through VS Code and renders recognized messages in a webview.

Where your trace is processed

Parsing happens in the VS Code extension host. Rendering happens in the webview. With Remote SSH, containers or another remote workspace, the extension host may run on that remote system; “local” does not mean it must run on your laptop.

What it does not do

The extension does not execute recorded tool calls, edit trace files, load remote images embedded in trace content, or upload traces to a RunTranscript service. Links in Markdown open externally only when clicked. Other installed extensions, VS Code itself and your remote host have their own privacy behavior.

Stored state

VS Code may retain preview preferences and state, including the search text, selected conversation, filters and position. Diagnostic errors may appear in the RunTranscript output channel. Review diagnostics before sharing them.

Website and support

This documentation site is hosted by GitHub Pages. It has no analytics scripts, advertising or third-party embeds. GitHub processes website requests under its own privacy statement. Public GitHub issues are visible to everyone. Use synthetic examples and remove secrets and private conversations before filing a report.

Distribution

The public repository contains documentation, synthetic examples and compiled extension releases. Implementation source is maintained privately. The distributed extension is MIT licensed; bundled libraries retain their own notices.
