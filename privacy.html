Privacy

The Unroll extension has no telemetry, analytics, account system or connection to any model provider. It reads the document you open through VS Code and draws the messages it recognizes in a webview.

Where your trace is processed

Parsing happens in the VS Code extension host. Rendering happens in the webview. With Remote SSH, containers or another remote workspace, the extension host may run on that remote machine, so “local” means “inside your VS Code setup”, not necessarily on your laptop.

What it doesn’t do

  • Run the tool calls recorded in a trace
  • Edit or save trace files
  • Load remote images embedded in trace content
  • Upload traces anywhere; there is no Unroll service

Links inside Markdown messages open in your browser only when you click them. VS Code itself, other extensions and your remote host have their own privacy behavior.

Stored state

VS Code may keep preview preferences and state such as the search text, selected conversation, filters and scroll position. Errors can appear in the Unroll output channel; review them before sharing.

This website

The site is hosted on GitHub Pages. It has no analytics, ads or third-party embeds, and its fonts are served from the same site. GitHub processes requests under its own privacy statement.

Filing issues

GitHub issues are public. Use synthetic examples, and remove secrets and private conversations before attaching anything.

Distribution

The public repository holds documentation, synthetic examples and compiled releases. Implementation source is maintained privately.
